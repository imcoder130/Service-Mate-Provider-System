Service Mate Provider System

📌 About the Project

Service Mate Provider System is an Android application designed to connect users with service providers and make it easier to access different services through a mobile application.

🛠️ Technologies Used

- Java
- XML
- Firebase
- Android Studio

✨ Key Features

- User-friendly Android application interface
- Service-related functionality for users
- Firebase integration for backend and data management
- Android-based frontend development
- Backend functionality using Firebase
- Application deployed and tested on a mobile device
